Strata 원본 v0.2.12 · IQ3_XXS 256K · MTP/DFlash2

이 패키지는 원본 Strata v0.2.12의 Windows CUDA 13 엔진 0.1.58과 같은 태그의 Python 서버·도구를 묶었습니다. Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS 모델 한 종류를 NVIDIA RTX A6000, Windows, 128GB RAM에서 쓰도록 준비했습니다. 이전 포크의 별도 sm86 엔진 수정이나 긴 문서 자동 고정 기능은 포함하지 않습니다.

필요한 파일

Windows 10/11 x64, NVIDIA 드라이버 580.65 이상, 충분한 SSD 여유 공간이 필요합니다. 모델 GGUF 두 조각은 저작권과 용량 때문에 ZIP에 없습니다. ISTA-DASLab의 원본 모델에서 받은 다음 파일을 압축 해제한 폴더의 models에 넣으세요.

models\Qwen3.8-Flash-Next-GSQ-RCO-IQ3_XXS-00001-of-00002.gguf
models\Qwen3.8-Flash-Next-GSQ-RCO-IQ3_XXS-00002-of-00002.gguf

기본 ZIP에 mmproj-Qwen3.8-Flash-Next-BF16.gguf, MTP 파일, Python, CUDA 라이브러리가 들어 있습니다. DFlash2를 쓸 때는 같은 릴리스의 strata-win-original-v0.2.12-iq3_xxs-256k-dual-dflash2.zip도 필요합니다. 추가 ZIP에는 원본에 고정된 DFlash2 Q4_0 pack이 들어 있습니다. 다른 양자화나 Unsloth GGUF로 위 두 파일을 바꾸지 마세요.

실행

  1. 기본 ZIP을 새 폴더에 풉니다. DFlash2도 쓸 경우 추가 ZIP을 같은 상위 폴더에 풀어 dflash2\qwen3.8-flash-next-dflash2.q4_0.pack이 기본 폴더 안에 놓이게 합니다. 이전 버전 폴더에 덮어쓰지 마세요.
  2. 위 GGUF 두 파일을 models에 복사합니다.
  3. MTP는 RUN-MTP.bat 또는 RUN.bat, DFlash2는 RUN-DFLASH2.bat을 실행합니다. 다른 방식으로 바꿀 때는 실행 중인 서버를 먼저 닫으세요. 첫 실행은 GGUF에서 pack과 토크나이저를 만들기 때문에 시간이 걸립니다.
  4. 브라우저에서 http://127.0.0.1:8080을 엽니다. 다른 앱의 OpenAI 호환 Base URL은 http://127.0.0.1:8080/v1입니다.

서버는 127.0.0.1에서만 수신하며 --offline으로 시작합니다. 원격 이미지 URL과 MCP 외부 도구 실행은 막히며, 로컬 파일 또는 요청에 넣은 이미지 데이터는 사용할 수 있습니다. 다른 PC에서 접속하도록 바꿀 때는 반드시 API 키도 설정하세요.

고정된 설정

항목값
컨텍스트262,144토큰. 입력과 출력을 합친 상한입니다. 입력이 256K에 가까우면 답변할 공간을 남겨야 합니다.
KV 캐시int8, GPU 상주 32,768토큰, 나머지는 시스템 RAM
생성 보조MTP 배치 파일은 원본 MTP(--spec 4), DFlash2 배치 파일은 원본 DFlash2 설정(--spec 6)을 사용합니다. 두 drafter를 동시에 올리지 않습니다.
이미지포함된 GPU 인코더와 mmproj 사용, 이미지 토큰 상한 1,024
프롬프트원본의 --prefill auto. A6000에서 원본 엔진이 청크 크기를 결정합니다.

원본 코드에서는 sm_86 GPU의 DFlash2가 MTP보다 느렸던 측정 사례를 기록합니다. RTX A6000의 실제 차이는 검증되지 않았으므로 두 방식 중 빠른 쪽은 직접 선택하세요.

RUN.bat은 실행할 때마다 prepare.py로 strata-iq3_xxs.json을 다시 만듭니다. 설정을 바꾸려면 생성된 JSON이 아니라 prepare.py를 수정하세요. 이 패키지는 이전 버전의 calibration-iq3_xxs.json을 사용하지 않습니다. 성능 향상 폭이나 출력 동일성은 RTX A6000 실기기에서 측정하지 않았습니다.

문제 확인

"필요한 파일이 없습니다"는 GGUF 이름과 위치를, "DFlash2 pack이 없습니다"는 추가 ZIP의 압축 해제 위치를, "드라이버"는 nvidia-smi를 확인하세요. 시작 중 메모리가 부족하면 다른 프로그램을 닫고 Windows 페이지 파일을 시스템 관리로 설정하세요. 실행 기록은 strata-iq3_xxs.log에 남습니다. ZIP의 SHA256SUMS.txt와 SOURCE.json으로 파일과 원본 버전을 확인할 수 있습니다.
