# 원본 Strata v0.2.12 폐쇄망 Windows 패키지: MTP와 DFlash2

원본 [Strata v0.2.12](https://github.com/Niko1221/Strata/releases/tag/v0.2.12)의 Windows CUDA 13 엔진 0.1.58, Python 서버·도구로 만들었습니다. 이 저장소의 v0.1.45용 sm86 엔진 수정, Xeon W-2245 조정, 캘리브레이션 파일은 적용하지 않았습니다.

두 ZIP을 같은 상위 폴더에 압축 해제하세요. 두 번째 ZIP은 첫 번째 ZIP의 `dflash2` 폴더에 모델 pack을 더합니다.

| 파일 | 내용 |
| --- | --- |
| [기본 ZIP](https://github.com/doha-230/Strata/releases/download/v0.2.12-offline-iq3xxs-256k-dual/strata-win-original-v0.2.12-iq3_xxs-256k-dual.zip) | 원본 엔진, 서버, Python, 이미지 인코더, MTP, MTP·DFlash2 실행 파일 |
| [DFlash2 추가 ZIP](https://github.com/doha-230/Strata/releases/download/v0.2.12-offline-iq3xxs-256k-dual/strata-win-original-v0.2.12-iq3_xxs-256k-dual-dflash2.zip) | 원본에 고정된 DFlash2 Q4_0 모델 pack, 출처 및 Apache-2.0 라이선스 |

기본 ZIP: 2,104,617,834바이트, SHA-256 `35e282f3f5a4ebdd580a2f696ddc6f80e6f64135ee820214f68e973be628f142`. DFlash2 추가 ZIP: 457,941,628바이트, SHA-256 `126c1aba16469a4f2bdba1cceb366a48c0b9ae13b10c09e6c26f25c5fb3d33ff`.

메인 모델인 `Qwen3.8-Flash-Next-GSQ-RCO-IQ3_XXS-00001-of-00002.gguf`와 `...-00002-of-00002.gguf`는 두 ZIP에 없으므로 별도로 받아 `models`에 넣어야 합니다. NVIDIA 드라이버도 별도 설치하며, 최소 버전은 580.65입니다.

`RUN.bat` 또는 `RUN-MTP.bat`은 MTP를, `RUN-DFLASH2.bat`은 DFlash2를 사용합니다. 다른 방식을 실행하기 전에 기존 서버를 닫으세요. 둘 다 256K 컨텍스트, int8 KV, GPU 상주 KV 32K, 원본 `--prefill auto`, GPU 이미지 입력, `127.0.0.1:8080`을 사용합니다. 첫 실행은 메인 GGUF에서 Strata pack과 토크나이저를 만듭니다. 자세한 절차는 ZIP 안의 `MANUAL.html`에 있습니다.

DFlash2 pack은 [incoai의 고정 리비전](https://huggingface.co/incoai/Qwen3.8-Flash-Next-DFlash2/tree/a22a1744e85c17364dcc54a6a420af7135d4c7f6)의 가중치를 원본 `tools/dflash2_pack.py --q4_0`으로 변환한 것입니다. 변환 결과는 원본 코드의 크기·SHA-256 고정값과 대조했습니다. `RUN-DFLASH2.bat`도 시작할 때 이를 확인하므로 빠진 파일이나 다른 pack으로 조용히 MTP로 전환하지 않습니다. 원본 코드에는 sm_86에서 DFlash2가 MTP보다 느렸던 측정 사례가 있습니다. RTX A6000에서 두 방식의 속도 차이는 측정하지 않았습니다.

빌드: `python tools/build_upstream_0212_offline_iq3xxs.py`. 원본 서버의 GPU 없는 테스트 376개와 패키지 설정 테스트 3개를 통과했습니다. 두 ZIP은 CRC 검사를, 엔진과 DFlash2 pack은 고정 해시 검사를 통과했습니다. Windows RTX A6000에서 실제 실행 또는 속도는 측정하지 않았습니다.
