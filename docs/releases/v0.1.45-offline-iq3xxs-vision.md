# 폐쇄망 Windows 패키지 v0.1.45

이 릴리즈는 [원본 Strata v0.1.45](https://github.com/Niko1221/Strata/releases/tag/v0.1.45)의 소스(커밋 `477ac13`), Windows CUDA 엔진, 이미지 인코더와 Python 서버를 사용합니다. Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS용으로 준비했으며 GPU 이미지 입력과 MTP를 기본으로 켰습니다.

## 다운로드

- [완성된 ZIP](https://github.com/doha-230/Strata/releases/download/v0.1.45-offline-iq3xxs-vision/strata-win-iq3_xxs-vision.zip)
- ZIP 크기: 2,039,005,358바이트
- ZIP SHA-256: `886e7bb1a8df50ac95051ab7f29b4bb66a5b7c312252fe36fcd0d006c25376b2`
- [압축 전 파일](https://github.com/doha-230/Strata/tree/main/offline/strata-win-iq3_xxs-vision) · [한국어 HTML 설명서](https://github.com/doha-230/Strata/blob/main/docs/OFFLINE_WINDOWS_IQ3XXS_KO.html)

포함: v0.1.45 Windows 엔진과 GPU 이미지 인코더, Python 3.12 및 의존성, CUDA 13 런타임·cuBLAS, `mmproj`, 변환된 MTP 런타임, 웹 앱, `MANUAL.html`, `CALIBRATE.bat`. 메인 LLM GGUF 두 조각과 NVIDIA 시스템 드라이버는 포함하지 않았습니다.

## v0.1.38 패키지에서 달라진 점

- 원본의 v0.1.39~v0.1.45 엔진·서버 수정 사항을 반영했습니다. IQ3_XXS 생성 속도, 긴 입력, Windows 파일 읽기, 이미지 대화 캐시, API 및 서버 처리가 변경되었습니다. 구체적인 속도 개선 폭은 사용하는 PC에서 측정해야 합니다.
- 원본 v0.1.45 Windows 배포 ZIP의 SHA-256(`a1d4cafb8319c253f3010ff118dbd5ed07c232056b939ac7735819559f3b859e`)을 검증해 엔진을 고정했습니다. 새 배포 파일에 포함된 `strata_kq.dll`도 함께 제공합니다.
- 오프라인 기본 설정은 32K 컨텍스트, int8 KV, GPU 이미지 입력, MTP `--spec 4`, 로컬 주소 `127.0.0.1:8080`입니다.

## 설치 또는 이전 버전에서 옮기기

새 ZIP을 새 폴더에 풀고, [원본 IQ3_XXS GGUF 두 조각](https://huggingface.co/ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF/tree/ed59f92082b1e93c0e96d60a8b11aab089b52f09/IQ3_XXS)을 그 폴더의 `models`에 복사하세요. 기존 v0.1.38 폴더에 있는 두 파일을 복사해도 됩니다. `RUN.bat`을 실행하면 pack과 설정을 준비합니다. 이전 설정과 캘리브레이션 파일은 복사하지 말고, 필요하면 새 폴더에서 `CALIBRATE.bat`으로 다시 측정하세요.

## 확인 범위

원본 엔진 ZIP의 게시된 SHA-256, 패키지 파일 목록과 CRC, 주요 파일 해시, 메인 GGUF 제외 여부, Python 구문과 설치 코드의 기본 검사를 확인했습니다. Windows 실기기에서의 실행과 속도는 아직 측정하지 못했습니다.
