# RTX A6000 폐쇄망 Windows 패키지

이 릴리즈는 [원본 Strata](https://github.com/Niko1221/Strata) v0.1.38 엔진을 NVIDIA RTX A6000 48GB VRAM / RAM 64GB Windows PC용으로 묶은 것입니다. 원본 Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS를 대상으로 하며, GPU 이미지 입력과 MTP를 기본으로 켰습니다.

폐쇄망 PC에는 ZIP을 복사해 압축 해제하세요. Git으로 받는 경우 큰 파일은 [별도 공개 Git LFS 저장소](https://github.com/doha-230/Strata-A6000-offline-assets)에서 내려받습니다. Git LFS를 설치한 뒤 `git lfs pull`을 실행해야 합니다.

## 포함된 것과 직접 준비할 것

**포함:** Windows용 Strata 본체·GPU 이미지 실행 파일, Python 3.12과 필요한 패키지, CUDA 13 런타임·cuBLAS, `mmproj-Qwen3.8-Flash-Next-BF16.gguf`, 변환된 MTP 런타임, 웹 앱, `MANUAL.html`.

**직접 준비:** NVIDIA 드라이버 580 이상과 [원본 GSQ-RCO IQ3_XXS GGUF 두 조각](https://huggingface.co/ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF/tree/ed59f92082b1e93c0e96d60a8b11aab089b52f09/IQ3_XXS)(합계 약 75.8GB). 메인 GGUF는 ZIP과 Git 폴더 모두에서 제외했습니다.

두 파일을 압축 해제한 폴더의 `models`에 다음 이름 그대로 넣으세요.

```text
Qwen3.8-Flash-Next-GSQ-RCO-IQ3_XXS-00001-of-00002.gguf
Qwen3.8-Flash-Next-GSQ-RCO-IQ3_XXS-00002-of-00002.gguf
```

Windows 10/11 x64, AVX2 지원 CPU와 NTFS SSD의 약 85GB 여유 공간을 권장합니다. RAM 64GB에서는 큰 프로그램을 닫고 Windows 페이지 파일을 시스템 관리로 두세요. `RUN.bat`을 실행하면 첫 시작에 GGUF 검사, pack과 토크나이저 생성이 진행됩니다.

기본값은 32K 컨텍스트, int8 KV, GPU 이미지 입력, MTP `--spec 4`, GPU 0번, 로컬 주소 `127.0.0.1:8080`입니다. 실행 후 `http://127.0.0.1:8080/health`에서 `"loaded": true`와 `"images": true`를 확인하세요. 설정 변경 방법은 `MANUAL.html`에 있습니다.

## 확인 범위

ZIP의 파일 목록과 CRC, 주요 파일 해시, 메인 GGUF 제외 여부를 확인했습니다. 빌드 정보와 실행 파일의 `sm_86` 코드는 RTX A6000을 대상으로 합니다. **Windows RTX A6000 실기기 실행과 속도는 아직 검증하지 못했습니다.**
