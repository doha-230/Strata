# 원본 Strata v0.2.12 폐쇄망 Windows 패키지

이 패키지는 [원본 Strata v0.2.12](https://github.com/Niko1221/Strata/releases/tag/v0.2.12)의 Windows CUDA 13 엔진 0.1.58과 같은 버전의 Python 서버·도구를 사용합니다. 이 저장소의 v0.1.45 전용 sm86 엔진 수정, Xeon W-2245 조정, 캘리브레이션 파일은 적용하지 않습니다. 원본으로 되돌려 새로 설치할 때 사용하세요.

- 대상: Windows 10/11 x64, NVIDIA RTX A6000, Xeon W-2245, RAM 128GB, Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS.
- 기본 설정: 262,144토큰 컨텍스트, int8 KV, GPU 상주 KV 32,768토큰, 원본 `--prefill auto`, MTP, GPU 이미지 입력, `127.0.0.1:8080`.
- 메인 모델 GGUF 두 조각과 NVIDIA 드라이버는 포함하지 않습니다. 엔진의 최소 드라이버 버전은 580.65입니다.
- ZIP은 완전한 독립 폴더이며, 이전 패키지에 덮어쓰지 않습니다. 압축을 푼 뒤 `MANUAL.html`을 열어 설치·실행 절차를 확인하세요.

패키지 파일: `strata-win-original-v0.2.12-iq3_xxs-256k.zip` (2,104,594,334바이트). SHA-256: `f65f14648dd123e41840b4ca0d8461776f948f01a83b03052c8726344dd56914`. 패키지 안의 `SOURCE.json`에는 원본 소스 커밋과 엔진 파일 해시가, `SHA256SUMS.txt`에는 중요한 실행 파일의 해시가 있습니다.

인터넷이 되는 빌드 PC에서는 `python tools/build_upstream_0212_offline_iq3xxs.py`로 다시 생성할 수 있습니다. 빌더는 원본 소스 커밋과 엔진 아카이브를 고정하고, 기존 패키지의 MTP 런타임 파일을 원본 v0.2.12 도구로 재생성한 결과와 대조합니다. 검증에는 원본 서버의 GPU 없는 단위 테스트 376개와 새 실행 설정 테스트 2개를 사용했습니다. ZIP의 CRC 검사와 원본 엔진 매니페스트 해시 검사도 통과했습니다. Windows RTX A6000에서 실제 실행 또는 속도는 측정하지 않았습니다.
