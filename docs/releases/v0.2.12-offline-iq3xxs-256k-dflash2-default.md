# 원본 Strata v0.2.12 폐쇄망 Windows 패키지: DFlash2 기본

원본 [Strata v0.2.12](https://github.com/Niko1221/Strata/releases/tag/v0.2.12)의 Windows CUDA 13 엔진 0.1.58, Python 서버·도구를 사용합니다. RTX A6000, Xeon W-2245, RAM 128GB와 Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS 모델을 대상으로 합니다. 이전 포크의 별도 sm86 수정, Xeon 조정, 캘리브레이션 파일은 적용하지 않습니다.

| 파일 | 내용 |
| --- | --- |
| [기본 ZIP](https://github.com/doha-230/Strata/releases/download/v0.2.12-offline-iq3xxs-256k-dflash2-default/strata-win-original-v0.2.12-iq3_xxs-256k-dflash2.zip) | DFlash2 기본 실행에 필요한 엔진, Python, 모델 pack, 이미지 인코더와 mmproj, 서버·도구·설명서 |
| [선택형 MTP 추가 ZIP](https://github.com/doha-230/Strata/releases/download/v0.2.12-offline-iq3xxs-256k-dflash2-default/strata-win-original-v0.2.12-iq3_xxs-256k-dflash2-mtp.zip) | MTP 가중치. MTP를 쓸 때만 기본 ZIP과 같은 상위 폴더에 압축 해제 |

기본 ZIP: 1,874,472,892바이트, SHA-256 `74a85ce9637af9064fd838ce22baf6c79e241efc540aa2af150b2833d968f71b`. 선택형 MTP ZIP: 688,099,960바이트, SHA-256 `fc546c57f62d68b4832f26faa771a5ce884cd525acb14104e674ea025b4d8f6d`.

기본 ZIP의 `RUN.bat` 또는 `RUN-DFLASH2.bat`은 DFlash2를 실행합니다. MTP 추가 ZIP을 풀었다면 `RUN-MTP.bat`으로 전환할 수 있습니다. 다른 방식을 시작하기 전에 실행 중인 서버를 닫으세요. 기본 ZIP에는 MTP 가중치가 없으며, DFlash2에는 MTP 레이어를 함께 올리지 않습니다.

두 방식 모두 262,144토큰 컨텍스트, int8 KV, GPU 상주 KV 32,768토큰, 원본 `--prefill auto`, 이미지 입력, 로컬 주소 `127.0.0.1:8080`을 사용합니다. 메인 모델 GGUF 두 조각과 NVIDIA 드라이버는 포함하지 않습니다. 드라이버 최소 버전은 580.65입니다. 두 GGUF를 `models`에 넣고 ZIP 안의 `MANUAL.html`을 따라 실행하세요.

DFlash2 pack은 [incoai의 고정 리비전](https://huggingface.co/incoai/Qwen3.8-Flash-Next-DFlash2/tree/a22a1744e85c17364dcc54a6a420af7135d4c7f6)의 가중치를 원본 `tools/dflash2_pack.py --q4_0`으로 변환했습니다. pack 크기와 SHA-256은 원본 코드의 고정값과 대조합니다. 원본 코드에는 sm_86에서 DFlash2가 MTP보다 느렸던 측정 사례가 있습니다. RTX A6000에서 실제 차이는 측정하지 않았습니다.

빌드: `python tools/build_upstream_0212_offline_iq3xxs.py`. 원본 서버의 GPU 없는 테스트 376개와 패키지 설정 테스트 4개를 통과했습니다. ZIP CRC, 엔진 매니페스트와 DFlash2 pack의 해시를 확인했습니다. Windows RTX A6000에서 실제 실행 또는 속도는 측정하지 않았습니다.
