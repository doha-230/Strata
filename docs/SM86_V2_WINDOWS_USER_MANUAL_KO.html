Strata A6000 sm86 v2 빌드 사용자 매뉴얼

Windows x64, RTX A6000(sm86), Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS용 추가 실행 파일입니다. 기존 폐쇄망 Windows 패키지를 먼저 준비하세요. 모델 설치와 일반 사용법은 패키지 안의 MANUAL.html에 있습니다.

검증 범위: CUDA 13.0.88과 Visual Studio 2022로 Windows Release 빌드에 성공했고, 실행 파일의 Windows x64 형식과 해시를 확인했습니다. RTX A6000에서 실행·정확도·속도는 아직 측정하지 않았습니다. 성능 향상 수치를 보장하지 않습니다.

1. 필요한 파일

  • 기본 패키지: strata-win-iq3_xxs-vision.zip. Python, 이미지 인코더, CUDA 13 라이브러리가 들어 있습니다.
  • 이번 빌드: strata-windows-sm86-cuda13.zip. 압축 안의 strata.exe와 strata_kq.dll을 사용합니다.
  • 원본 GSQ-RCO IQ3_XXS GGUF 두 조각과 NVIDIA 드라이버 580 이상은 기본 패키지 설명서대로 준비합니다.

이번 빌드 ZIP만으로는 실행할 수 없습니다. 기존 패키지의 CUDA 13 런타임과 cublas64_13.dll 등이 필요합니다. 이 실행 파일은 sm86 전용이므로 다른 GPU용 기본 실행 파일을 대체하는 용도로 사용하지 마세요.

2. 기존 패키지에 적용

  1. 실행 중인 RUN.bat 창을 닫아 서버를 종료합니다.
  2. 기본 패키지의 engine\strata.exe와 engine\strata_kq.dll을 다른 위치에 복사해 백업합니다.
  3. 이번 빌드 ZIP을 풀고 두 파일을 기본 패키지의 engine 폴더에 복사합니다. 기존 파일을 덮어씁니다. strata-vision.exe, python, models, mtp 폴더는 그대로 둡니다.

새 실행 파일을 복사한 뒤 기본 RUN.bat을 실행하면 A6000의 IQ3_XXS gate/up 또는 IQ4_NL down 프롬프트 경로에서 v2 커널이 자동으로 켜집니다. 환경 변수를 추가하거나 실행 스크립트를 고칠 필요가 없습니다.

3. 기본값과 끄는 방법

v2는 sm86에서 IQ3_XXS gate/up 또는 IQ4_NL down을 사용하는 층의 프롬프트 전문가 연산에 기본 적용됩니다. 다른 형식과 다른 GPU의 기본값은 바뀌지 않습니다. 커널 초기화에 실패하면 기존 fused 커널로 돌아갑니다. 생성(decode) 속도 향상을 뜻하는 옵션은 아닙니다.

기존 fused 커널과 비교하려면 기본 패키지 폴더의 PowerShell에서 다음처럼 실행합니다.

$env:STRATA_PF_V2 = '0'
.\RUN.bat

기존 MMQ 경로로 되돌리려면 새 PowerShell 창에서 다음처럼 실행합니다.

$env:STRATA_PF_FUSED = '0'
.\RUN.bat

환경 변수는 해당 PowerShell 창에 남습니다. 기본값으로 다시 실행할 때는 새 창을 열거나 Remove-Item Env:STRATA_PF_V2, Env:STRATA_PF_FUSED -ErrorAction SilentlyContinue를 입력합니다.

4. 128K–256K 입력 설정

기본 패키지는 32K 컨텍스트입니다. 실제 128K 또는 256K 입력을 쓰려면 패키지의 prepare.py에서 "--max-context", "32768"을 각각 "--max-context", "131072" 또는 "--max-context", "262144"로 바꾼 뒤 서버를 다시 시작합니다. strata-iq3_xxs.json은 RUN.bat을 실행할 때 다시 생성되므로 직접 수정하지 않습니다.

컨텍스트를 늘리면 KV 캐시 메모리와 첫 토큰까지 걸리는 시간이 증가합니다. 128GB RAM과 A6000에서도 256K의 실사용 가능 여부와 속도는 이 빌드에서 확인하지 않았습니다.

5. 적용 확인

  1. http://127.0.0.1:8080/health에서 "loaded": true를 확인합니다.
  2. IQ3_XXS 모델로 프롬프트 하나를 처리한 뒤 패키지의 strata-iq3_xxs.log를 엽니다.
  3. strata: prompt experts on v2 IQ kernels (sm_86)가 있으면 v2 경로가 사용된 것입니다. unavailable 메시지가 있으면 기존 커널로 대체되었습니다.

Windows PowerShell에서 실행 파일 해시를 확인하려면 다음을 입력합니다.

Get-FileHash .\engine\strata.exe -Algorithm SHA256

검사한 SHA-256을 릴리스 페이지의 strata.exe 값과 비교하세요.

6. 원래 실행 파일로 되돌리기

서버를 종료하고 2단계에서 백업한 strata.exe와 strata_kq.dll을 engine 폴더에 다시 복사한 뒤 기존 RUN.bat을 실행합니다. 바이너리 교체 없이 v2만 끄려면 위의 STRATA_PF_V2=0을 사용합니다.

소스와 Windows 빌드 기록은 이 매뉴얼을 받은 릴리스 페이지에서 확인할 수 있습니다.
